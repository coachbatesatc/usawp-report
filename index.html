Google Sheet Setup
One-time setup — about 5 minutes
1
Create a Google Sheet
Go to sheets.google.com, create a new spreadsheet, name it "USAWP Encounter Reports."
2
Open Apps Script
In the sheet click Extensions → Apps Script.
3
Paste the Script
Delete any existing code and paste the script below.
4
Save
Press Ctrl/Cmd+S. Name it "USAWP Report Logger."
5
Deploy as Web App
Click Deploy → New deployment. Type: Web App. Execute as: Me. Who has access: Anyone. Click Deploy.
6
Authorize
Click Authorize access, sign in, allow permissions.
7
Copy the Web App URL
Copy the URL shown (ends in /exec).
8
Paste URL in Delivery Settings
Paste it into the Delivery Settings field on the Report tab. You can also paste it below.
